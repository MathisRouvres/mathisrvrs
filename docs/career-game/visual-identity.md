# Charte graphique — Mode Carrière

Identité **indépendante** du portfolio (pas de tokens `--accent` / Inter / neon).

## Direction

Bulletin de centre de formation : pelouse claire, encre dense, signal terre cuite pour l’action secondaire d’alerte, vert pin pour le primaire.

## Typographies

- Display : **Syne**
- Corps : **Figtree**

## Couleurs (CSS vars `.career-root`)

| Token | Rôle |
|-------|------|
| `--cg-bg` | Fond atmosphère |
| `--cg-surface` | Panneaux |
| `--cg-ink` | Texte principal |
| `--cg-pitch` | Primaire / CTA |
| `--cg-signal` | Contreparties / accent chaud |
| `--cg-ok` | Succès / atouts |
| `--cg-danger` | Erreurs / suppression |

## Composants

Préfixe `cg-` : boutons, cartes, champs, chips, choix fondateurs, carte joueur.

Fichier source : `src/features/career/styles/career-theme.css`.
